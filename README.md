## Проекты

### 1. Печатная форма документа «Заказ»
**Что сделано:**  
- Печать одного или нескольких документов
- Вывод шапки, табличной части, итогов
- Разделитель страниц между документами
- Расшифровки: клик в любом поле товара → карточка товара с описанием, клик по Покупателю/Поставщику → открытие формы элемента соответствующего контрагента
- Сохранение Логотипа организации в отдельный справочник Хранимые Файлы
- Вывод Логотипа в табличный документ
- Отображение одного или нескольких документов на общей форме
- Выгрузка в Excel файл

**Ключевые механизмы:** Модуль менеджера документа, запрос с левым соединением, параметры макета, обработка события расшифровки, асинхронный диалог выбора файла, выгрузка табличного документа в Excel, работа с хранилищем значений (логотип).

**Технологии:** Макет табличного документа, запрос с соединением, управляемые формы

## Как запустить проекты

### Вариант 1. Выгрузка базы (.dt)
1. Скачать [по ссылке](https://disk.yandex.ru/d/HFdrbEPrRC_mnQ) информационную базу
1. Создай новую информационную базу.
2. В конфигураторе выбери «Администрирование → Загрузить информационную базу».
3. Укажи файл `dt/DemoBase_Portfolio.dt`.
4. Запусти 1С в режиме предприятия.

### Вариант 2. Внешние обработки (.epf)
1. Открой 1С в режиме предприятия.
2. Выбери «Файл → Открыть».
3. Выбери нужную обработку в папке `epf/`.
